This page exists because Firefox closes an extension popup the moment a file picker opens, so the import has to live in a tab.

2. What is in it

Each saved window opens as a new window. Your current tabs are not touched, moved or closed. Restored tabs come back unloaded, so nothing is fetched until you click it.

Restored groups lose the 🕒 from their names, which hands them to you permanently — Tabo will not re-sort or rename them. It has to work this way: Firefox gives no way to restore a tab's last-active time, so a restored archive would otherwise collapse into “this week” on the next pass. Add the 🕒 back by hand if you want a group managed again.
