Tabo

This version of Firefox has no tab groups API, so recency groups are unavailable. Unloading still works.
This reorders the tabs in your strip. Pinned tabs and tabs already in your own groups are left alone.

Tabo's groups are ordinary Firefox tab groups, marked with a 🕒. Rename one — dropping the clock — and it becomes your group: Tabo stops adding tabs to it, stops moving it, stops renaming it, and never touches it again. That is the way to keep a week, month or year group permanently. Keep the 🕒 and Tabo will rename it back to match the dates on its next pass.

Unloading frees a tab's memory and keeps it in the strip. Music, calls, screen sharing, pinned tabs and the tab you are on are never unloaded.

Closing is permanent. Firefox can reopen closed tabs with Ctrl+Shift+T, but only for 14 days — export a backup first if you want them longer.

Export writes every window, group and tab to a JSON file — your own groups too, not just Tabo's. Import opens each saved window fresh, leaving your current tabs alone, and restores tabs unloaded so a big file costs no memory.
